## Overview

**ACoolAgent** is the central intelligence hub for the ACoolECOSYSTEM — an AI-orchestrated command layer that powers:

- 🤖 **WhatsApp AI Assistant** — intelligent, 24/7 customer-facing automation
- 🧠 **Agent Hierarchy** — nested sub-agents with role-based delegation (RBAC)
- 📡 **Real-Time Event Bus** — webhook-driven signals across every ecosystem vertical
- 📊 **Analytics Dashboard** — unified KPIs across revenue, engagement, and operations
- 🔐 **Secure Access** — JWT-based auth with full audit trails
- 🌐 **Knowledge Base Integration** — grounded in ACoolKNOWLEDGEBASE via RAG
